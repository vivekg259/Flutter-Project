# Excelerate Next Learning Portal 🚀📱

A functional, mobile-first micro-learning application built with **Flutter** for the **Excelerate Virtual Internship (Week 2 Milestone)**. The app provides learners with an intuitive interface to browse technical courses, monitor ongoing events, submit feedback, and view platform updates.

---

## 🌟 Week 2 Milestone Achievements

* **UI Translation:** Successfully translated low-fidelity wireframes into fully styled, interactive Flutter widgets.
* **Brand Consistency:** Applied Excelerate’s official branding tokens—featuring deep navy blue headers (`#003366`), vibrant blue action buttons, orange highlights, and clean typography.
* **Interactive Navigation:** Implemented responsive routing across all core screens via a global `BottomNavigationBar`.

## 💡 Screen Highlights & Functionality

1. **Login Screen:** Authentication portal featuring Excelerate branding, email/password fields, and options to sign in or create an account.
2. **Home Dashboard:** Displays active metrics (*3 Courses In Progress*, *1 Certificate Earned*), upcoming session calendars, and quick links to Webinars, Community, and Support.
3. **Programs Catalog:** A searchable, scrollable list showcasing offered courses (*Advanced Flutter & Dart Mastery*, *Applied Data Science with Python*, *MERN Full-Stack Bootcamp*).
4. **Program Details Screen:** Displays granular course details, instructor info (*Andrew Ng*), key skill tags (*Machine Learning*, *Pandas*, *NumPy*), and an enrollment trigger.
5. **Course Feedback Screen:** Interactive form featuring course dropdowns, 5-star ratings for content and instructors, and pace feedback options (*Too Slow*, *Just Right*, *Too Fast*).
6. **Updates / Notifications:** Real-time alert feed for live sessions, assignment evaluations, and course updates.
7. **User Profile:** Dedicated user space displaying user account information (*Test User*), certificates, subscriptions, and sign-out capabilities.

## 🛠️ Setup & Installation Instructions

To run this project locally, make sure you have the [Flutter SDK](https://docs.flutter.dev/get-started/install) installed and configured on your machine.

---


1. **Clone the repository:**
   ```bash
   git clone https://github.com/vivekg259/Flutter-Project
   
2. **Navigate into the project directory:**
 ```Bash
cd excelerate_flutter_app
 ```

3. **Install project dependencies:**
 ```Bash
flutter pub get
 ```

4. **Launch the app on an emulator or connected device:**
 ```Bash
flutter run
 ```
